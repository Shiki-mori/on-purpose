# 实现当前编码任务

## 步骤

1. 读 `docs/assignment/assignment-book.md` 第 13 节，确定编号最小且状态为「未开始」或「进行中」的任务。
2. 只读该项正文，加上任务书第 3 节。共享约定读 [reference.md](reference.md)，不要另起名字。
3. 该项点名的设计或需求章节再打开。不要为了后面的任务提前改行为。
4. 只改该项文件和该项行为。更晚的消息 `type` 可以出现在 `constants.js` 的常量里，但不要写它们的处理函数。
5. 写完后对照该项验收表。验收在使用者的 Chrome 中进行：`chrome://extensions` 加载 `extension/`，普通窗口打开哔哩哔哩。Cursor 内置浏览器不能加载这个扩展。
6. 每一行都对照过之后，把第 13 节该项改为「已完成」并写上日期。有没做的行就不要改成已完成，把缺口写进备注。AC-14 在无法休眠时的记法以任务书为准。

## 不要做的事

- 一次做两项任务。
- 在代码里改已经确认的交互。要改时先修订需求说明书或系统设计说明书。
- 把弹出页或内容脚本接到 `chrome.storage`，或给扩展加网络请求、打包工具、ES Module。
