# 有目的

在 Chrome 里打开哔哩哔哩时，先记下这次想做什么；用到自己设定的分钟数后，再问现在实际在做什么。记录留在本机，用来复盘。扩展只提醒，不替你决定要不要继续看。

第一版只在哔哩哔哩的 https 页面上工作，包括 `bilibili.com` 和 `*.bilibili.com`。没有上架，需要用开发者模式从本仓库加载。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions`。
2. 打开右上角的「开发者模式」。
3. 选择「加载未打包的扩展程序」，选中本仓库里的 `extension` 文件夹。
4. 用普通窗口打开哔哩哔哩。无痕窗口默认没有这个扩展。

工具栏里会出现名为「有目的」的图标。改完 `extension/` 里的文件后，在扩展页重新加载。重新加载会清掉正在走的计时；记录、目的、打断选项、间隔、按钮位置，以及还没到期的暂时关闭都会留下。

## 目的询问

窗口标题是「本次使用的目的是什么」。

- 这一轮里第一次打开哔哩哔哩页面时会问。关掉全部哔哩哔哩标签页，或退出浏览器之后再打开，算新的一轮。
- 主页每次整页打开或刷新都会再问，即使刚才已经回答过。
- 其他页面在这一轮里已经回答或跳过之后，再打开或刷新，不再问。还没回答就刷新，会继续问。
- 在站内点到另一个地址、但页面没有整页重新加载时，不会重新判断要不要问。

选中一个目的后可以写备注，再点「确认」。备注可以空着。只选中、不确认，不会写入记录。点「跳过」会立刻记下一次跳过并关掉窗口，没有备注。窗口会挡住页面，直到确认或跳过，没有别的关闭方式。询问开着的这段时间不计入后面的计时。

窗口下方可以添加目的，添加后马上就能选。改名和删除在工具栏弹出页里做。

一开始有这七项：学习、游戏攻略、追番、健身、生活经验、关注更新、其他。

## 时长打断

所有哔哩哔哩标签页共用一个计时。页面在后台、视频暂停、电脑休眠，时间都继续算。

- 目的询问全部确认或跳过之后，从零开始，用「首次打断间隔」。默认 5 分钟。
- 这一轮打断里，每个打开着的哔哩哔哩标签页都要各自回答。全部完成之后，若还开着哔哩哔哩，再从零开始，用「再次打断间隔」。默认也是 5 分钟。
- 两个间隔在弹出页里分开改。只接受大于或等于 1 的整数。

到点后，窗口标题是「现在在做什么」，并挡住页面。若这一轮已经有过目的询问，窗口上方会显示最近一次的目的和当时写下的备注。正在播放的视频会暂停。

选「其他」或自己添加的选项后可以写备注，再点「确认」。点「关闭当前标签页」会先记下这一次，再关掉当前标签页，没有备注框。点右上角「关掉」不写记录，大约 5 秒后这个窗口会再出现，并再次暂停播放。用浏览器自己的关闭按钮关掉标签页，不写「关闭当前标签页」这条记录。

同一个页面上如果两件事碰到一起，先显示目的询问，确认或跳过之后再显示时长打断。

## 暂时关闭

每个哔哩哔哩页面右下角有一个半透明的「暂停」按钮。点一下展开面板，拖动可以换位置，松手后的位置会在各个哔哩哔哩页面和重启之后保留。

- 「10 分钟」和「30 分钟」点下去就生效。
- 自定义框每次打开都显示 10。填大于或等于 1 的整数再点「确认」。小于 1 或不是整数时不会开始，输入处会提示。
- 生效后按钮变成「至 HH:mm」，面板里还有完整的截止时间。已经在暂时关闭中时再设一次，从这一次起重新计算，不保留原来剩下的时间。

暂时关闭期间不弹时长打断，共用计时也不走。目的询问仍会按上面的规则出现。截止时间按实际时间走，休眠也算。到期时如果还有哔哩哔哩标签页，会立刻弹出时长打断，不再等间隔。当时已经没有哔哩哔哩标签页，则只结束这次关闭，下次打开不会补弹。

询问或打断出现时，窗口盖在这个按钮上面。

## 弹出页

点工具栏里的「有目的」图标。从上到下是：

1. **间隔。** 「首次打断间隔（分钟）」和「再次打断间隔（分钟）」。改完后点击输入框外面，或按 Enter。
2. **目的。** 可以改名或删除。删除前浏览器会问一次「删除这个目的？」。新目的在询问窗口里添加。
3. **打断选项。** 这里添加、改名或删除自己加的选项。「其他」和「关闭当前标签页」不能改，也不能删。
4. **记录。** 新的在前。每条有时间、来源（「目的询问」或「时长打断」）、选择或回答，以及当时写过的备注。记录不能删除。

名称不能为空，也不能超过 200 个字。保存失败时窗口留着，并提示「没能保存，请再试一次」。

## 数据留在本机

目的、备注、回答和设置只写在这台电脑的 Chrome 里，扩展不会把它们发到网上。卸载扩展会一起丢掉这些记录，本版不能导出，也不能同步到别的设备。
