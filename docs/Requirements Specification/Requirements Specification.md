## 1. 引言

### 1.1 产品目的

个人在 Chrome 中使用网页版哔哩哔哩时，用两次询问留下记录：打开时声明这次想做什么；使用达到自己设定的分钟数后，再问现在实际在做什么。使用者据此复盘，并可以在一段自己设定的时间里暂停「到时打断」。

产品只做提醒和记录。使用者自己决定是否继续浏览。

### 1.2 读者与后续文档

本文供后续编写系统设计说明书和分步实现时使用。运行形态已经在背景第 6 节选定：以开发者模式加载的 Chrome 扩展（Manifest V3），不上架。数据存放、界面注入位置、计时在进程中的落点，写入系统设计说明书，并沿用该选型。

### 1.3 写法

- **应当**：已定需求，实现和验收都要满足。
- 需求编号在全文稳定使用。插入新需求时另给编号，不重排已有编号。

## 2. 术语与范围

### 2.1 术语

| 术语 | 含义 |
| --- | --- |
| 主页 | 使用 https，主机名为 `bilibili.com` 或 `www.bilibili.com`，路径为 `/` 的页面。查询参数和片段不影响这一判断。 |
| 哔哩哔哩标签页 | 使用 https，主机名为 `bilibili.com`，或以 `.bilibili.com` 结尾的页面所在标签页。 |
| 视频播放页 | `www.bilibili.com` 上路径以 `/video/` 开头的页面。 |
| 番剧播放页 | `www.bilibili.com` 上路径以 `/bangumi/` 开头的播放页面。 |
| 搜索页 | 主机名为 `search.bilibili.com` 的页面。 |
| 推荐页 | 独立打开热门或推荐列表的页面（例如路径包含 `/v/popular` 的 `www.bilibili.com` 页面）。主页上的推荐区域视为主页。 |
| 主要页面 | 主页、视频播放页、番剧播放页、搜索页、推荐页。用于 T-17 允许的入口退让。 |
| 一轮使用 | 从出现哔哩哔哩标签页开始，到不再存在任何哔哩哔哩标签页或退出浏览器为止。 |
| 目的询问 | 弹出的窗口，询问这次使用的目的。 |
| 时长打断 | 到时或暂时关闭到期后弹出的窗口，询问现在在做什么，并挡住当前浏览。 |
| 共用计时 | 所有哔哩哔哩标签页共同使用的这一轮计时。走动时按实际流逝的时间计算。设置单位为分钟。 |
| 首次打断间隔 | 目的询问完成或跳过后，到下一次由计时触发的时长打断，所等待的分钟数。 |
| 再次打断间隔 | 一轮时长打断全部完成后，到下一次由计时触发的时长打断，所等待的分钟数。 |
| 暂时关闭 | 在使用者设定的截止时间之前，不弹出时长打断。截止时间按实际时间计算，电脑休眠也计入。到期时若仍有哔哩哔哩标签页，立刻弹出时长打断。 |
| 复盘 | 在扩展图标的弹出页中，按时间查看以往的目的、打断回答、跳过和「关闭当前标签页」记录。 |

哔哩哔哩若调整路径，视频、番剧、搜索和推荐以使用者实际打开的那类页面为准。

### 2.2 本版包含

- 在哔哩哔哩网页上进行目的询问、时长打断、暂时关闭和记录复盘。
- 使用者维护目的列表；打断使用另一套选项列表。
- 个人在自己的 Chrome 中以开发者模式加载使用。
- 站点相关的网址范围、初始目的与「询问、计时、记录、暂时关闭」流程分开，便于以后改代码接入其他网站。第一版只接入哔哩哔哩。
- 询问窗口、打断窗口、暂时关闭展开面板和工具栏弹出页使用深色主题。

### 2.3 本版不包含

- 哔哩哔哩客户端、手机浏览器、Chrome 以外的桌面浏览器。
- 发布到 Chrome 网上应用店或脚本市场。
- 账号登录、多设备同步、把记录发给他人。
- 自动屏蔽、隐藏或过滤短视频与推荐流，以及替使用者判断某条内容是否无意义。
- 在第一版的界面里添加第二个网站。
- 导出记录、统计图表、按目的汇总时长。
- 永远停用时长打断的开关。暂时关闭一定有截止时间。
- 记录使用者用浏览器自身控件关闭标签页的行为。
- 删除单条复盘记录。
- 浅色主题，以及深色与浅色的切换。

## 3. 功能需求

### 3.1 目的询问

**FR-1.1** 询问文案为「本次使用的目的是什么」。窗口使用深色主题。

**FR-1.2** 目的询问在下列时机弹出：

1. 打开任一哔哩哔哩标签页时，若当时刚开始一轮使用（在此之前已经没有哔哩哔哩标签页，包括刚启动浏览器），弹出目的询问。这一条不限于主页。
2. 主页每次完成新的页面加载时都弹出，包括刷新，以及新开一个主页标签页。已经回答或跳过也要再问。询问尚未完成时刷新，也要再问。
3. 非主页上的目的询问尚未完成时，刷新该页后继续弹出。

已经在本轮使用中回答或跳过，并且仍有哔哩哔哩标签页开着时，再打开视频页、搜索页或其他非主页，不再弹出目的询问。已经完成的非主页被刷新时，也不再弹出。

**FR-1.3** 目的询问应当列出当前目的列表中的每一项，并提供「跳过」。初始列表见 FR-5.2，其中包含「其他」。列表里已有「其他」时，窗口不再另画一个「其他」。

**FR-1.4** 使用者选中某个目的后，窗口出现一个备注框，可以填写一条备注，再确认。备注不是必填。确认后写入一条记录，并关闭询问窗口。只选中、尚未确认时，不写入记录。

**FR-1.5** 点击「跳过」后，应当立即写入一条「跳过」记录，并关闭询问窗口。跳过不出现备注框，也不附带备注。

**FR-1.6** 备注属于这一次记录，不属于目的项本身。修改目的名称不改写已有记录中的备注。

目的仍在列表中时，以往记录里该目的的名称显示为当前名称。该目的被删除后，以往记录保留删除前的名称，之后不再跟着别的修改变化。

**FR-1.7** 目的询问挡住所在页面，直到使用者确认或跳过。窗口不提供除此之外的关闭方式。尚未确认也尚未跳过时刷新页面，加载完成后再次挡住并询问。这段从弹出到确认或跳过的时间不计入共用计时。

**FR-1.8** 暂时关闭生效期间，目的询问仍按 FR-1.2 出现。

**FR-1.9** 目的询问窗口的列表处可以添加新目的。添加后立即出现在当前列表中，可以用于这一次选择，并在之后的询问中继续出现。询问窗口不提供编辑和删除。

### 3.2 时长打断

**FR-2.1** 所有哔哩哔哩标签页共用一个计时，包括同一浏览器里的多个窗口。

**FR-2.2** 共用计时正在走动时，依据实际流逝的时间。页面在后台、视频暂停、电脑休眠期间，时间都继续累计。不以前台可见时长或播放进度为准。目的询问挡住页面期间、暂时关闭期间，计时不走动，见 FR-1.7 和 FR-3.7。

**FR-2.3** 下列情况结束后，下一轮从零开始，并且当时没有正在走动的计时：

- 退出浏览器
- 不再存在任何哔哩哔哩标签页（包括关掉所有窗口、但 Chrome 仍在系统后台运行）
- 开发时重新加载扩展（见 C-2）
- 开始暂时关闭（见 FR-3.7）

只关闭一部分哔哩哔哩标签页，或刷新页面，不因此把计时清零。若清零时目的询问尚未完成，仍按 FR-1.7 处理，完成或跳过之后才开始计时。

**FR-2.4** 首次打断间隔和再次打断间隔是两个设置，单位都是分钟，彼此独立。由计时触发的时长打断使用其中对应的一个间隔，询问文案为「现在在做什么」。窗口使用深色主题。

计时开始走动后，实际时间达到当前所用间隔时弹出时长打断。设定为 1 分钟时，页面在后台或视频暂停的情况下也应当在约 1 分钟时弹出，不得等使用者回到该页之后再重新累计这一分钟。允许实现上有短暂延迟；延迟应当明显短于所设置的分钟数。

哪个间隔生效见 FR-2.12。默认值和取值范围见 FR-5.5。

**FR-2.5** 到达弹出时机时，每个已经打开的哔哩哔哩标签页都弹出时长打断。这一轮尚未全部完成时，新打开的哔哩哔哩标签页也弹出，并需要单独回答。

每个窗口挡住所在页面，直到该页确认一项回答、点击「关闭当前标签页」，或关掉这个窗口。某一个标签页完成回答后，其他标签页的窗口保持打开，并各自再写一条记录。

窗口出现时，暂停该标签页正在播放的视频或番剧。使用者关掉窗口后，若这次暂停之前正在播放，则恢复播放。窗口再次出现时再次暂停。

**FR-2.6** 打断窗口的选项列表与目的列表相互独立。初始只有「其他」和「关闭当前标签页」。使用者可以添加自己的打断选项，并编辑或删除自己添加的选项。不能删除，也不能修改「其他」和「关闭当前标签页」。

选择自己添加的选项或「其他」后，出现一个备注框。

**FR-2.7** 备注不是必填。确认后只写入当前标签页的这一条记录，并关闭该标签页上的打断窗口。全部打开中的打断窗口都完成之前，不开始下一次计时。

**FR-2.8** 点击「关闭当前标签页」后，应当先写入一条记录，再关闭当前标签页。写入失败时，不关闭标签页。该点击不出现备注框，也不需要再点一次确认。

这一记录只对应打断窗口里的该按钮。使用者用浏览器自身的关闭控件关掉标签页时，不新增记录。该标签页上未完成的打断随之结束。

该按钮应当能关闭使用者自己打开的标签页，包括这个窗口里只剩这一个标签页的情况。若关闭后已经没有哔哩哔哩标签页，计时处于 FR-2.3 的清零状态。若仍有其他未完成的打断窗口，这一轮继续。若打断窗口都已结束且仍有哔哩哔哩标签页，按 FR-2.12 开始下一次计时。

**FR-2.9** 若本轮使用中已有目的询问记录，打断窗口展示其中最近一条的目的（或「跳过」）和备注。没有目的询问记录时，不展示对照内容。备注当时没写，则对照区不显示备注。

**FR-2.10** 时长打断窗口可以被关掉。关掉不写入记录，视同该页尚未回答。5 秒后在该标签页再次弹出，并再次挡住页面、暂停播放。这 5 秒内该页可以操作。5 秒内不开始下一次共用计时。

刷新后若该页这一轮打断仍未完成，加载完成后立即再次弹出，不等待 5 秒。

**FR-2.11** 暂时关闭的截止时间尚未到达时，不弹出时长打断。暂时关闭到期且当时仍有哔哩哔哩标签页时，立即弹出时长打断，不等待首次或再次打断间隔。当时已经没有任何哔哩哔哩标签页，则不补弹，下次打开也不因为这次到期而立即打断。

**FR-2.12** 计时从零开始后，下一次由计时触发的打断使用哪一个间隔：

- 目的询问被确认或跳过：从零开始，使用首次打断间隔。窗口开着的时间不计入。
- 一轮时长打断的各个窗口都已结束，且仍有哔哩哔哩标签页：从零开始，使用再次打断间隔。
- 开始暂时关闭：计时清零并暂停，两个间隔都不走动。到期触发的打断不依赖这两个间隔；该轮打断全部完成后，再按上一条使用再次打断间隔。

同一标签页上若目的询问和时长打断都要出现，先只显示目的询问。确认或跳过之后，再显示时长打断。

### 3.3 暂时关闭

**FR-3.1** 暂时关闭只停止时长打断。它不删除历史记录，也不停止目的询问。

**FR-3.2** 使用者以分钟为单位设定关闭时长。开始后应当保存截止时间。重启浏览器后，未到期的暂时关闭仍然有效。取值见 FR-5.5。

入口展开后提供：

- 预设「10 分钟」和「30 分钟」。点击预设后立即按该时长开始；若当时已在暂时关闭中，则按 FR-3.6 重新计算截止时间。
- 自定义分钟数。输入框初次显示 10。填写并确认后，按所填分钟数开始或重新计算。这一次输入不改写输入框下次打开时的初始值。

小于 1 或不是整数时，不开始暂时关闭，并在输入处提示。展开面板使用深色主题。

**FR-3.3** 每个哔哩哔哩页面都应当有暂时关闭入口，不要求先回到主页。入口是一个半透明按钮，能看见它底下的页面内容。位置不固定，可以拖动到视口内的任意位置。全站共用使用者最后放下的位置；刷新、切换哔哩哔哩页面和重启浏览器后仍在该位置。尚未拖动过时，按钮位于视口右下角并留出边距。

目的询问或时长打断出现时，窗口盖在这个按钮之上。

若某类哔哩哔哩页面无法放入该入口，可以退到只放在主要页面上。退让时，主要页面上的入口仍然必须可用，并在实现说明中列出未覆盖的页面。

**FR-3.4** 暂时关闭生效时，入口应当显示截止时间。到期且当时至少有一个哔哩哔哩标签页时，应当立即弹出时长打断。

**FR-3.5** 到期时若没有任何哔哩哔哩标签页，不补弹。下次打开哔哩哔哩时，只按目的询问和共用计时自己的规则进行，不因为已经过去的那次到期立刻弹出时长打断。

**FR-3.6** 暂时关闭期间，使用者可以从入口延长。延长从点击预设或确认自定义的时刻起，按所选分钟数重新计算截止时间，并覆盖原来的截止时间。

**FR-3.7** 一开始暂时关闭，就把共用计时清零并暂停。暂停持续到暂时关闭结束。到期后的立即弹出不依赖这段计时。截止时间本身仍按实际时间走向，休眠期间也算。

### 3.4 复盘

**FR-4.1** 点击浏览器工具栏中的扩展图标，在弹出页中查看记录。弹出页使用深色主题。记录按时间排列，新的在前。每条记录展示：

- 时间，至少精确到分钟，并保留能区分先后的时刻
- 来源：「目的询问」或「时长打断」
- 选择或回答
- 备注（当时写了才展示）

**FR-4.2** 各类操作写入的「选择或回答」如下：

| 操作 | 来源 | 选择或回答 |
| --- | --- | --- |
| 确认一个目的 | 目的询问 | 该目的的当前名称；目的已删除时为删除前的名称 |
| 跳过 | 目的询问 | 跳过 |
| 确认一个打断选项 | 时长打断 | 该选项的名称 |
| 确认「其他」（时长打断） | 时长打断 | 其他 |
| 关闭当前标签页 | 时长打断 | 关闭当前标签页 |

目的列表中的「其他」按普通目的记录，选择或回答为「其他」。

**FR-4.3** 记录保存在本机，只追加，不提供删除。重启浏览器后仍然可以查看。卸载扩展会一并失去这些记录；本版不提供导出。

**FR-4.4** 复盘就是这个弹出页，不另开扩展页面。弹出页中提供目的的编辑和删除，并列出目的以便操作。添加不在弹出页中，见 FR-1.9。

打断选项的添加、编辑和删除也在这个弹出页中完成。列表与目的列表分开。「其他」和「关闭当前标签页」在这里可见，但不能删除或改名。

首次打断间隔和再次打断间隔也在这个弹出页中修改。

### 3.5 列表与设置

**FR-5.1** 使用者应当能够添加、编辑和删除目的项。添加后的目的出现在之后的目的询问中。删除后不再出现在之后的询问中。添加、编辑、删除的位置见 FR-1.9 和 FR-4.4。

**FR-5.2** 初始目的为下面七项，顺序如下，之后允许修改：

1. 学习
2. 游戏攻略
3. 追番
4. 健身
5. 生活经验
6. 关注更新
7. 其他

**FR-5.3** 目的列表与打断选项列表分开保存。修改其中一套，不改变另一套。

**FR-5.4** 首次打断间隔、再次打断间隔、目的列表、打断选项，以及暂时关闭按钮的位置，在重启浏览器后保持不变。尚未到期的截止时间也保持不变。

**FR-5.5** 首次打断间隔和再次打断间隔的初始值都是 5 分钟。确认清单只给出一个打断间隔默认值，因此两处都用 5 分钟。暂时关闭自定义输入初次显示 10 分钟。预设 10 分钟和 30 分钟始终可用。

这三处分钟数都接受大于或等于 1 的整数，不设上限。小于 1 或不是整数的输入不保存，并在输入处提示。

**FR-5.6** 新安装时打断选项只有「其他」和「关闭当前标签页」。

## 4. 运行约束

这些约束来自已经选定的运行形态，描述使用者可以观察到的安装和生命周期，不代替系统设计。

**C-1** 扩展运行在个人的 Chrome 上，以开发者模式加载本机目录，不上传到商店。

**C-2** 在 `chrome://extensions` 重新加载扩展后，进行中的共用计时清零；已保存的记录、目的列表、打断选项、分钟设置、按钮位置，以及尚未到期的暂时关闭截止时间仍然保留。

**C-3** 界面文字使用中文。本文已经规定的按钮和询问文案使用其中的原文。

**C-4** 目的、备注、回答、选项列表和设置只保存在本机，扩展不把这些内容发送到网络。

**C-5** 生效网址、该站的初始目的和页面范围，应当与询问、计时、记录、暂时关闭的流程分开配置。第一版只配置哔哩哔哩。第一版不要求在界面中新增网站。

**C-6** 目的询问、时长打断、暂时关闭展开面板和工具栏弹出页使用深色背景与浅色文字。本版只做深色，不提供主题切换。
