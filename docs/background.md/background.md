# 项目背景

我平时经常使用网页版哔哩哔哩<[https://www.bilibili.com/](https://www.bilibili.com/)>。

我使用该网站的目的有查看学习视频，游戏攻略，追番，健身视频，生活经验等。但是在使用过程中，我经常把大量时间浪费在刷无意义的短视频上面。我希望能限制自己刷无意义的短视频。

## 具体方法

1. 在首次打开哔哩哔哩网页（主链接<[https://www.bilibili.com/](https://www.bilibili.com/)>）时，弹出窗口询问本次使用的目的是什么。弹出的窗口询问时提供选项，每个选项可输入备注，保存每一次选择与备注记录。用户后续可复盘查看这些记录。对于目的，需要支持用户自定义添加。
2. 在使用哔哩哔哩时长达到一定时间（具体时长可供用户自己设置，单位为分钟）后，弹出窗口打断当前浏览，询问用户现在在做什么。该功能可被设置为“一段时间内（用户自定义）关闭”。需要有方便的关闭功能入口，做到在哔哩哔哩的主要页面（包括视频播放页，搜索推荐页，主页等等）可随时关闭。

## 实现方式

我使用Chrome浏览器。比较浏览器插件、篡改猴脚本或者其他方式，选择最合适的实现方式。暂定仅供个人使用，不会上传到插件或脚本market。

## 开发流程

按照软件工程开发规范，在编写代码之前先写完整的需求说明文档，系统设计文档等等。不要一次性完成过多功能。应分步逐条实现完整项目。

暂时只考虑哔哩哔哩网页。项目需要具备扩展性，可在以后方便地通过修改代码来实现对其他链接的相同限制方式。
